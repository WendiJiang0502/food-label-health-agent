# 配料证据展示与50组模拟评测

结果页新增逐条件结论、证据缺失原因及后续动作。每个商品可展开配料证据，查看糖类配料、糖醇、其他甜味剂、乳/蛋来源、纤维相关配料及原文片段，并访问商品官网。
明确标识官网资料尚未完成包装复核；来源异常时展示待核对；无资料与规则未命中分开说明。未列出成分不代表不含，也不推算总糖。

## 评测口径

50组用例以固定合成商品建立显式预期答案：18个应符合、11个应不符合、20个应未知、1个未评估。覆盖上限边界、缺糖、八类过敏限制、精确配料回避、相对比较的多种表达、多条件组合、缺原商品、口径差异、异常与过期资料。
预期答案基于固定合成配料和数值人工编写规则期望（由助手编制，非外部人工标注集），不是从当前程序输出生成。规则回归全部50组符合预期；假通过0，明确冲突漏判0。
另在现有39条酸奶记录上运行48组普通查询，有18组出现官网资料初步符合候选。来源异常和过期这2组是合成故障测试，不计入真实来源覆盖分母。
同品牌不同规格并非独立配方；有些用例是边界或表达变体。结果不代表真实用户成功率、医疗安全准确率或RAG对照提升。
模拟评测不写入真实用户需求队列，不调用付费模型或OCR。

## 验证

全量701项测试通过。浏览器使用真实来源数据渲染有资料、资料缺失、来源异常及明确冲突状态，检查键盘展开、来源链接、移动端边界、空结果清理与脚本错误。
逐组结果：results.json。固定用例：src/food_label_agent/evaluation/data/yogurt_queries_v2.json。运行器：python -m food_label_agent.evaluation.yogurt_validation --input <候选JSON> --output <结果JSON>。

## 后续限制

仍需真实用户查询及独立人工标注验证。当前无法从缺失的官网字段补出总糖。另设计文档与其工具侧元数据存在既有不同步，可单独刷新设计文档元数据，本轮未扩大修改范围。
