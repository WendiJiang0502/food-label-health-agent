# 糖与重要配料证据补充

本轮公开资料检索未找到能可靠匹配当前酸奶商品及版本的新增总糖数值，因此总糖新增0条。没有用碳水、蔗糖添加比例、无蔗糖声明或旧版检测代替总糖。

已为正式队列中38条具有配料文字的商品生成逐条配料证据，保留原文片段、来源链接、字段路径和来源版本。4条存在既有来源异常，证据保留待核对；其余34条中的正向出现统计如下（商品数可重叠）：

| 配料类别 | 明确出现的商品数 |
| --- | ---: |
| 糖类配料，如白砂糖、糖浆 | 18 |
| 乳来源 | 34 |
| 纤维相关配料，如菊粉、抗性糊精 | 9 |
| 糖醇 | 1 |
| 其他甜味剂 | 1 |
| 蛋来源 | 1 |

这些是官网文本解析结果，不是新的包装审核或实测结果。没有检测到的成分仍不支持“不含”结论。糖醇、其他甜味剂和糖类配料分别保存，均不推算总糖。

卡士餐后一小时无蔗糖款的官网配料明确出现麦芽糖醇、赤藓糖醇、甜菊糖苷、蛋黄粉、菊粉等，已可追溯到其原始配料文本。补充蛋黄粉、蛋黄液、稀奶油等精确词条后，现有过敏排除逻辑也能识别相应来源。

## 接入位置

正式商品发现接口和网页初步筛选响应均返回 ingredient_profile 字段；月度更新改变配料文本时会重新计算，不保存脱离原文的旧标记。页面现有逐约束冲突说明继续可用；本轮没有新增独立配料展示面板。

## 糖资料线索处理

- 厂家官网：简爱公开产品数据、卡士具体口味营养表仍未取得总糖字段。
- 检索到的旧测评把碳水称为含糖量，或仅检测蔗糖，且年代、规格无法与当前记录匹配，未入库。
- 日本明治资料未作为中国大陆同名商品的配方依据。
- 未将食物成分表中的通用酸奶数值复制到具体商品。

仍需的证据是当前规格版本的明确糖标签，或能对应商品版本的厂家资料/检测报告。完整标签缺糖不代表糖为零。
