# 个人约束安全判断试用集 v1

个人约束类案例使用原有文件 [internal_pilot_dataset_v1.json](./internal_pilot_dataset_v1.json)，其中除通用解释案例 `case_010`、`case_012`、`case_013`、`case_014`、`case_015` 外，其余 15 个案例均属于本类。

这些案例必须经过个人约束安全工作流，并检查过敏原、营养限制、替代品复核和最终安全门。

通用解释类案例单独位于 [internal_pilot_general_explanations_v1.json](./internal_pilot_general_explanations_v1.json)，不得因为没有用户约束而进入个人安全判断节点。
