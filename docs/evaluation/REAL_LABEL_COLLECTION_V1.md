# 真实标签试用集采集规范 v1

目标：收集 50 张真实食品标签，并形成至少 20 个端到端用户任务。OCR 不是本阶段唯一指标；每张标签必须有人工确认后的事实，才能进入安全判断。

## 每张标签需要记录

- `label_id`：稳定编号，例如 `real_001`；
- `image_path`：本地图片路径，不提交包含隐私的原图；
- `category`：食品类别；
- `jurisdiction`：默认 `CN`；
- `confirmed_facts`：人工确认后的配料、营养表、过敏原提示和包装声称；
- `source_note`：图片来源和是否允许内部评测；
- `reviewer`、`reviewed_at`：人工确认记录。

## 推荐覆盖配额

- 过敏原直接冲突：10 张；
- 复合配料或过敏原信息不完整：8 张；
- 营养限制：10 张；
- 包装声称：8 张；
- 添加剂解释：6 张；
- 有替代品需求：5 张；
- 应当拒答或证据不足：3 张。

同一产品可以覆盖多个类别，但每张图片至少设计一个用户问题。

## 安全要求

- 不录入姓名、地址、订单号或其他个人信息；
- 原图默认只保存在本地，不提交到 Git；
- `confirmed_facts` 必须来自标签或人工确认，不能由模型补写；
- 不确定的字段填写 `null` 或 `unknown`，不要猜测；
- 严重过敏案例必须明确预期状态和禁止声明。

完成录入后运行：

```bash
PYTHONPATH=src ./.venv/bin/python scripts/validate_real_label_dataset.py
```
