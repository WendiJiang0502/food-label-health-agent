## 决策与发现

- 决策：健康主页统计只描述“记录次数、类型和活跃日”，不自动解释风险、达标或健康程度。理由：避免将自填数据和视觉颜色误导为医疗判断。
- 决策：底部导航将扫描动作置中并视觉突出，历史和个人页分列两侧。理由：扫描仍是产品主动作，同时让持续记录入口保持稳定可达。
- 决策：MCP 工具边界统一捕获 `RuntimeError` 并转换为受控工具失败。理由：远程依赖错误应由 Agent 的可审计失败路径处理，而不能让确定性安全结果随调用异常丢失。
- 发现：仅扩展异常包装即可复用既有 `_tool_failure` 和最终安全门；无需修改过敏原规则或伪造降级法规证据。

### 一般风险

- 健康统计和导航主要依赖静态前端合同测试，可能遗漏布局溢出、指示器定位、焦点移动和读屏体验问题。建议：在桌面与移动视口执行 Playwright 和无障碍检查。
