# ADR-004：节点上下文、检查点与授权记忆

状态：Accepted  
日期：2026-08-09

## 背景

Milestone 4 要求 Agent 不把全部历史与证据无差别送入每个节点，同时允许当前分析在中断后恢复。跨会话保存用户约束属于长期记忆，必须与工作流检查点分离，并以用户明确授权和完整的数据控制能力为前提。

## 决策

### 节点上下文

上下文构建器将状态分为当前任务、已确认事实、用户约束和检索证据四层，并为 `normalize_label`、`evaluate_safety`、`react_orchestrator`、`final_safety_gate` 定义独立字段白名单。每次构建记录上下文摘要、包含与排除字段、估算 Token 数和预算状态，不记录模型内部思维链。

预算不足时依次压缩低优先级证据、规范化配料和附加未知项。用户约束与已经产生的 `avoid` 结果不得因预算被删除；未确认标签字段不得进入已确认事实上下文。

### 短期检查点

SQLite 以追加方式保存显式序列化的 `AgentState`。首次写入返回随机恢复令牌，数据库只保存令牌摘要；同一 `request_id` 的后续写入、读取历史和删除都必须提供该令牌。序列化器强制删除原始图片并标记 `images` 已脱敏。

### 长期记忆

长期记忆与检查点使用独立表和授权生命周期。只有 `explicit_consent=true` 才能创建授权；访问令牌只在授权时返回一次。当前允许保存：

- 用户明确声明的约束；
- 回答形式偏好；
- 用户确认过、且复用时必须重新核对当前标签的修正记录。

API 支持查看、修改、单项删除、清除全部内容并撤销授权。图片、完整对话、内部思维链、诊断和未经确认的健康推断由服务端字段校验拒绝。

## 安全边界

- 检查点和长期记忆不能共享访问令牌；
- 服务端不持久化令牌明文；
- 原始图片永不进入检查点或长期记忆；
- 记忆写入失败不能改变当前确定性安全评估；
- 历史标签修正只能作为待复核信息，不能覆盖当前包装；
- 本地 SQLite 能力令牌不替代多用户生产环境的账户认证、传输加密和租户隔离。

## 后果

Milestone 4 具备可测试的最小上下文、可恢复短期状态和用户可控长期记忆。后续节点可复用同一上下文构建边界；迁移到生产存储时必须保持显式序列化、图片脱敏、令牌校验和授权撤销语义。
