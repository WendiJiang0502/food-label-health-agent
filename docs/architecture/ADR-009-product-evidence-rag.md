# ADR-009 商品证据 RAG 与需求补齐队列

日期：2026-10-03。状态：已实施，正式服务启用。

后续扩展见 [ADR-010](ADR-010-product-intent-field-evidence-evaluation.md)：明确营养查询现已进入程序比较，并增加字段证据与场景评测；下文自由文本范围描述记录初始版本。

## 决策

法规和商品使用独立语料。商品 RAG 同时索引当前目录标签、Open Food Facts 详情与腾讯 OCR 草稿；先过滤地区、日期、用途类别和排除商品，再进行 BM25 与向量混合召回、RRF 合并和独立重排。商品内容视作不可信数据，不执行其中指令。

商品证据保留商品 ID、证据 ID、版本摘要、来源链接和层级。向量按模型、维度和文本摘要缓存在正式 SQLite 中，内容改变后自然使用新缓存键。配置 `FOOD_LABEL_PRODUCT_RAG_PROFILE` 默认继承法规检索配置，支持 `bm25`、`hybrid_tfidf`、`hybrid_dense`、`hybrid_dense_rerank`。离线测试明确使用 TF-IDF；远程失败返回降级状态，不伪装成功。

检索顺序接入现有替代品候选流程，但独立复核、过敏限制、证据有效期及程序营养比较仍决定推荐资格。目录命中也不等于已获推荐资格；外部资料和 OCR 草稿不会因召回分数高而变成可推荐商品。对话工具只传入可信上下文中的已确认标签和个人限制，保留当前营养表及计量基准，不接受模型自行编造用户约束。

自由文本输入用于用途和口味检索。营养排序目标沿用个人设置；例如需要“糖更少”的确定性比较时，应已选择控糖目标。检索文本出现糖、钠等字段，会记录相应资料缺口，但不会据此宣称产品低糖或安全。

## 补齐和月度执行

相关外部商品写入 `completion_queue`，同一商品的所有证据合并缺口，避免 OCR 草稿排在前面时丢失原始字段缺口。队列记录需求次数、商品证据摘要、缺字段和时间，不保存原始用户查询或健康档案。

月度后台服务按队列需求优先级补抓详情、识别包装；已获得字段从缺口中移除，资料齐备后仍需标签复核。服务沿用实际日历月计划，搜索不会立即触发重复网络抓取。腾讯 OCR 默认开启，草稿保持待审核，缺图或识别失败不填造数据。周期、最近成功时间和下一次检查沿用知识库状态接口。

## 页面和隐私

替代品页面提供可选需求输入、检索状态、证据折叠区、缺口和原文链接。远程检索会发送商品查询和候选证据，页面隐私说明与 `/api/health` 中 `product_rag` 展示这一行为。证据摘录使用文本节点呈现，不能执行其中 HTML。

## 验证和范围

- 自动测试 650 项通过，包括持久向量缓存、数据变更、来源过滤、降级、未知重排 ID、草稿分层、缺口合并、补齐优先级和聊天营养基准。
- 正式数据真实接口验证返回 `hybrid_dense_rerank`，无降级警告，14 个待核实商品入队。
- 桌面 1440px 和手机 390px 浏览器渲染验证了检索输入、草稿标识、字段缺口、降级说明和安全文本展示，无页面脚本错误。证据展示测试使用明确的测试数据，不等同端到端召回质量评估。
- 网页及后台服务已重启，月度检查下一轮为 2026-11-03。
- 快照见 `artifacts/product-rag-live-2026-10-03.json`：122 个外部候选详情已查询，66 个有配料文字、58 个有糖数值、30 个有 OCR 草稿，外部候选人工复核数为 0。不同字段统计不能相加，也不代表同一批商品资料齐全。
- OCR 138 次图片尝试中 101 次失败，另有 106 个图片字段缺失；官方网站复查上一轮不可用。系统与接线完成不代表所有商品已补齐，无法由缺失或模糊来源推断真实配料。
