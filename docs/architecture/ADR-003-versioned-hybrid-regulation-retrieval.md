# ADR-003：版本化法规混合检索

状态：Accepted  
日期：2026-08-09

## 背景

法规层原先只有 BM25、主题和标准号加权，适合标准编号与精确术语，但不能满足北极星中“关键词 + 向量 + 重排 + 版本过滤”的 Milestone 2 完成标准。

## 决策

`search_food_regulations` 使用 `hybrid_bm25_tfidf_rerank_v1`：

1. 先按法域、适用日期、主题和显式标准号过滤候选条款；
2. 对候选分别执行 BM25 关键词召回；
3. 使用领域概念增强的 TF-IDF 稀疏 embedding 做余弦向量召回；
4. 按条款索引合并两路结果，避免同一条款被重复返回；
5. 使用 BM25、向量、主题、标准号和权威等级做确定性融合重排；
6. 返回条款级来源、版本窗口、内容哈希以及每一路检索信号。

向量在本地按当前候选集构建，不调用外部 embedding 服务，不发送法规文本，也不依赖模型预训练记忆。领域同义概念表是显式、可评审的数据，当前覆盖过敏原交叉接触、乳来源、营养声称和添加剂等核心查询。

## 安全边界

- 过期或尚未生效的条款在召回前即被排除；
- 明确查询某一标准版本时，不回退到其他版本；
- 没有适用官方条款时返回 `unknown`；
- 重排不能改变条款的适用状态或权威等级；
- 所有引用必须保留官方链接、条款、页码或公告位置及内容哈希；
- 向量相似度只影响召回和排序，不能单独生成合规结论。

## 发布评测

固定基准覆盖现行与未来版本的过敏原规则、营养声称、添加剂标准和无适用证据场景。以下指标作为发布阻断项：

- Recall@K 低于阈值；
- 任一检索绕过混合链路；
- 返回非官方或不可追溯证据；
- 返回不适用或非预期版本；
- 无证据场景未正确拒答。

当前同时记录 MRR，用于后续扩大法规语料后的排序回归。

## 后果

Milestone 2 具备可离线运行、可解释和可测试的真实混合检索链。未来可以将稀疏 embedding 替换或并联为经过评测的中文稠密 embedding，但必须保留相同的版本过滤、证据字段、发布评测和安全门。
