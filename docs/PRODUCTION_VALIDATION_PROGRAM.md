# 生产验证与运营计划

本计划只定义可复核的完成标准，不把尚未发生的采集、用户研究或专家审核写成已完成。

## OCR 真实包装基准

- 公开试用最低 50 张；购买或严重过敏决策最低 200 张。
- 每张必须保留原图、SKU/规格、采集日期、人工真值、复核人和使用授权。
- 采样矩阵至少覆盖反光、曲面、小字、竖排、模糊、复杂表格、折痕和低照度；每层不少于 20 张，允许一图多层。
- 单独报告字符错误率、配料 token recall、过敏原 recall、营养素—数值配对准确率和低质量阻断 recall。
- 严重过敏门槛：过敏原 recall 100%；任何漏检都是 release blocker。
- 对腾讯 OCR 执行峰值并发、超时、限流、错误码、重试幂等和凭证失效演练。

## 目录与包装审核运营

- 每类至少 3 个不同配方、至少 2 个品牌；品牌占比、过期率、实物背标率、目标营养字段率与可购买率均进入发布报告。
- 实物图片必须绑定 exact SKU/规格、日期、哈希和两名不同复核人；官方网页截图不能代替包装照片。
- 一级复核 SLA 为 2 个工作日，二级复核 SLA 为 3 个工作日；改版、下架或证据到期自动回到队列。
- 排序不得接受付费覆盖安全规则；品牌合作、广告和佣金必须在卡片与方法页同时披露。

## 用户验证

- 首轮招募 8–12 名目标用户，至少覆盖过敏照护者、控糖用户和普通标签阅读者。
- 在真实或模拟超市任务中测量首次扫描完成率、OCR 修正确认耗时、正确找到证据的比例、拒答满意度和备选点击率。
- 不以“喜欢界面”代替任务成功；严重过敏任务中的错误购买意向必须为 0。
- 记录 7/30 日留存、单次 OCR/RAG/人工复核成本和用户愿付价格，再决定是否扩大健康趋势模块。

## RAG 与 Planner

- 建立 GB 2760—2024 完整限量表及 2011/2025/2027 双版本适用日期语料。
- 法规专家对来源、条款、日期和拒答进行盲评；困难负例与标签文本提示注入必须单列。
- Planner 基准不得只报告总体准确率；冲突处理、工具失败、注入和越权动作分别设 blocker。
