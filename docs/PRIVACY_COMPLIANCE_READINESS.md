# 隐私与合规发布清单

本文是工程门禁说明，不是隐私政策或法律意见。只有经实际运营主体与律师批准、发布并填写对应生产配置后，release profile 才能解除相关 blocker。

## 已由产品代码执行

- 图片不进入长期记忆；工作流序列化会移除原图。
- 长期记忆必须由用户明确授权，并使用独立 capability token 访问。
- 默认保留期为 30 天，可通过 `FOOD_LABEL_MEMORY_RETENTION_DAYS` 缩短或调整；应用启动时自动清理超期记忆。
- 用户可查看、修改、逐项删除、撤销授权，也可通过 `GET /api/v1/privacy/export` 导出完整档案数据。
- `DELETE /api/v1/privacy/profile` 会硬删除该档案的记忆项和授权记录。
- Cookie 写请求执行同源校验；健康与 API 响应禁止缓存。

## 发布前必须由外部责任人完成

1. 由实际运营主体发布隐私政策与服务条款，并填写 HTTPS URL。
2. 律师审核敏感个人信息单独同意、处理必要性、未成年人、投诉、泄露响应、备份删除和跨境数据路径；将审核编号写入 `FOOD_LABEL_LEGAL_REVIEW_ID`。
3. 与腾讯 OCR、远程模型及其他受托处理方确认数据用途、保存、地域、再委托和删除条款；将批准记录写入 `FOOD_LABEL_PROCESSOR_AGREEMENT_ID`。
4. 配置真实隐私联系渠道 `FOOD_LABEL_PRIVACY_CONTACT`。
5. 未建立可核验的监护人同意前，将 `FOOD_LABEL_MINOR_ACCESS_POLICY` 保持为 `blocked`。
6. 对主库、WAL、备份与日志执行一次可复核的删除演练，并保存日期、执行人、恢复点和结果。

## 当前边界

共享站点口令不是账户系统；它只适合受控邀请测试。用户级身份、设备撤销、密码恢复、租户隔离、数据库静态加密和集中密钥管理仍是公开多用户发布的独立 blocker。
